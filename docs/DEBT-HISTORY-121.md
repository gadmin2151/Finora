# История долгов · сайт и Android 1.21

Опубликовано 12 октября 2026 года. На сайте: **Долги → История долга**; в Android:
**Финансы → Долги → История долга**. Видны создание, добавления и все частичные/полные
возвраты, дата операции, счёт, примечание и остаток после каждой записи. После полного
погашения включите показ закрытых долгов, чтобы открыть прежнюю историю.

Новые записи отображаются сверху по времени внесения. Отменённые операции остаются
видимыми, но не участвуют в расчётах. Для долга, внесённого как ранее существовавший,
начальный остаток показан отдельно: дата первоначальной передачи денег не хранилась.
Пагинация не ограничивает общие итоги. Существующие ограничения прав сохранены:
на сайте раздел долгов доступен администраторам; Android и API допускают чтение
участником организации. Просмотр не создаёт финансовых операций.

## Изменения

- `backend/app/debt_history.py`, `backend/app/api.py`: чтение существующего ledger,
  ограниченная пагинация, проверка организации, общие итоги и остатки в одном SQL snapshot.
- `web/src/DebtHistory.tsx`, `web/src/pages/Planning.tsx`, типы, стили и перевод:
  окно истории, загрузка, повтор запроса, скрытие кэшированных данных при 403/404.
- Android `data/DebtHistory*`, `ui/DebtHistoryDialog.kt`, FinanceController/FinanceScreen,
  ApiClient и локализация: нативная история, пагинация и отсечение устаревших ответов.
- Регрессионные тесты backend и Android; исправлен фиксированный clock fixture
  прежнего push-теста и точная область loopback в debug network policy.

Финансовый алгоритм записи и схема БД не менялись. Зависимости не добавлялись.
Новый endpoint: `GET /api/debts/{id}/history?offset=0&limit=50`, максимум 200 строк.
Для истории в APK требуется обновлённый сервер; старый сервер даст ошибку чтения.

## Проверки

- Полный PostgreSQL suite: **613 passed, 1 skipped**, 11 subtests passed.
- Готовый Linux AMD64 image: **34 passed, 2 skipped** в тестах ledger/долгов;
  эти пропуски требуют PostgreSQL и покрыты полным PostgreSQL запуском.
- Web: lint, TypeScript, production build, **37 тестов**; настоящий браузер с тестовым
  API проверил обычный/узкий экран 390 px, частичные возвраты, добавления, отмены,
  исходный остаток, закрытый долг, страницы, retry и отзыв доступа после кэширования.
- Android: **243 unit-теста**; форматирование; debug/release lint без ошибок;
  два UI-сценария при font scale **1.0 и 1.8**, четыре снимка просмотрены.
- Подписанное обновление **1.20 → 1.21** прошло без удаления между версиями;
  прежний сертификат и firstInstallTime сохранены. Offline cold start дошёл до
  экрана входа без падения. Вход под реальным аккаунтом не выполнялся.
- Полный Ruff lint/format и проверка dependency lock прошли. В финальном Git также
  нормализованы только импорт моделей Alembic и формат/исполняемый флаг существующего
  генератора APK manifest; поведение этих вспомогательных файлов сохранено.

Физический телефон и Google Play не проверялись. Имеющиеся lint warnings и предупреждение
Starlette остаются; новых ошибок в runtime API/worker после установки не обнаружено.
