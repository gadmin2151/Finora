# Finora — origami wallet identity

The selected icon is the mint origami wallet holding a warm gold coin. The user selected this concept on 25 September 2026. The charcoal, jade, pale mint and gold palette is shared by the Android launcher, web identity, authentication and loading states.

- Source artwork: `artifacts/design-1.4/finora-origami.png` (local design export).
- Web asset: `web/public/finora-icon.png`.
- Android asset: `android/app/src/main/res/drawable-nodpi/finora_symbol.png`.
- Monochrome adaptive icon: `android/app/src/main/res/drawable/ic_finora.xml`.
- Generation mode: built-in image generation; approved artwork resized to 512 × 512 for application assets.

## Final generation prompt

Use case: logo-brand. Create ONE finished premium Android app icon artwork for 27G Finora Personal Finance, a modern personal budgeting and receipt scanning app. The user rejected a plain F letter as uncreative. New concept: a sculptural origami wallet / folded upward wing made of three broad mint jade facets, protectively cradling one luminous warm golden coin. Make a striking, simple, original symbol, instantly legible at 48px. The silhouette should feel like a clever folded pocket and upward motion, not a generic initial, bank logo or clipart. Rich tactile 3D product icon, smooth matte ceramic mint with restrained beveled highlights, deep evergreen inner folds, one small satin gold circular coin, beautiful soft studio shadows. Frontal with very slight isometric depth, balanced and centered. Palette: pale mint #C5F4DC, jade #82DDB5, evergreen #123A32, charcoal #101715, warm gold #F0CB8C. 1024 square. The main symbol must fit completely within the central 60% of the image, occupying x=21%-79%, y=21%-79%, with comfortable padding for Android adaptive icon circular cropping. Background is a full-bleed uniform dark graphite-green #101715, subtle soft glow behind symbol only, no rounded-square frame, no outer mockup or presentation. No text, no letters, no numbers, no currency symbols, no watermark, no multiple variants. High contrast, elegant iconic silhouette, polished craft.
