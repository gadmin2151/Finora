## Границы проверки

Физический телефон не был подключён: камера проверена с эмулируемым сенсором, QR — на синтетическом MEV-коде. Полевая проверка фокусировки, бликов и длинного чека на конкретной камере телефона остаётся после установки. API распознавания уже существовал на сервере; эти тесты проверяют мобильную передачу данных и получение результатов, а не точность AI на всех видах молдавских чеков.

CI выпускает подписанный APK только при настройке signing secrets; локально доставленный APK подписан постоянным отдельным ключом Finora. Для ключа создана зашифрованная age-копия; ключи, пароли и тестовые credentials не входят в Git, Docker context и APK.
